Mini Redis in Java

About the Project

Mini Redis is a beginner-friendly project built using Java to explore the fundamentals of how an in-memory key-value store works.

The goal of this project is to learn core programming concepts while gradually developing a simplified version of a Redis-like system.

Technologies Used

- Java
- Java Development Kit (JDK)

Current Progress

- Created the initial Java program.
- Compiled and executed the program locally.

Learning Goals

- Understand key-value data storage.
- Practise Java programming.
- Explore how Redis-like systems handle commands and data.
- Gradually add more functionality.

Future Improvements

- Implement key-value storage.
- Add commands such as "SET", "GET", and "DEL".
- Handle multiple commands.
- Add persistence and networking as advanced features.
